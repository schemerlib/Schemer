Field Documentation

◆ alpha

double Schemer::Config::alpha = 0.0

Stability parameter (\alpha).

Controls the order of the fractional derivative, restricted to (0, 2]. A value of 2.0 gives standard Gaussian diffusion. Values less than 2.0 produce superdiffusion (Lévy flights) with heavy tails, making long jumps more likely.

◆ beta

double Schemer::Config::beta = 0.0

Skewness parameter (\beta).

Controls the left-right bias of the diffusion, restricted to [-1, 1]. A value of 0 gives a balanced, symmetric spread, negative values lean left, and positive values lean right.
