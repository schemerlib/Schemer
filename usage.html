Usage

This page shows how to use the library. Everything is available after including a single header:

#include <Schemer/Schemer.h>
Schemer.h
Main header file for the Schemer library.

All classes live in the Schemer namespace. A typical program has three steps:

  1. Configure the simulation with Schemer::Builder.
  2. Build a Schemer::Runner and advance it in time with Schemer::Runner::run.
  3. Read the state or write it to a file or stream.

Complete, runnable programs are in the examples/ directory and are shown at the [bottom of the page](20usage_examples).

Quick start

#include <Schemer/Schemer.h>
int main() {
Schemer::Runner runner = Schemer::Builder()
.set_alpha(1.5)
.set_length(20.0)
.set_num_intervals(200)
.set_dt(0.01)
.build();
runner.run(500); // advance 500 steps, t = 500 * dt
Eigen::VectorXd p = runner.get_values();
runner.save_result("result.tsv");
}

By default the simulation starts from a Dirac delta at \(x = 0\), which is placed in the middle of the domain. No force and no resetting are applied.

Configuring a simulation

Every Schemer::Builder setter returns a reference to the builder, so calls can be chained. Parameters are only checked when you call build() or build_setup(). Invalid values throw std::invalid_argument.

Physical parameters

Method Field Default Valid range Meaning
set_alpha(double) Schemer::Config::alpha 0.0 (must be set) \((0, 2)\) Stability index. Smaller values give heavier tails.
set_beta(double) Schemer::Config::beta 0.0 \([-1, 1]\) Skewness. Must be 0 when \(\alpha = 1\).
set_sigma(double) Schemer::Config::sigma 1.0 \(\ge 0\) Scale (diffusion coefficient \(K\)).

Grid and time stepping

Method Field Default Meaning
set_length(double) Schemer::Config::length 40.0 Length of the spatial domain.
set_num_intervals(Eigen::Index) Schemer::Config::num_intervals 1000 Number of intervals \(N\). The grid has \(N + 1\) points.
set_dt(double) Schemer::Config::dt 0.001 Time step \(\Delta t\). A warning is printed if dt > 1.
set_theta(double) Schemer::Config::theta 0.5 Time scheme: 0.0 explicit, 0.5 Crank–Nicolson, 1.0 implicit.

The grid spacing is Config::get_dx() = length / num_intervals. The number of points is Config::get_size() = num_intervals + 1.

Note
The step matrix is dense and of size \((N+1) \times (N+1)\). Memory use and build time grow quickly with num_intervals.

Position of the origin

The origin \(x = 0\) is where the initial Dirac delta is placed. It is also the default reset target.

  • set_zero_middle() (default) puts it at index num_intervals / 2.
  • set_zero_index(Eigen::Index i) puts it at grid index i, where \(0 \le i \le N\).
  • set_zero_distance(double d) puts it at distance d from the left edge, where \(0 \le d \le L\). The distance is rounded to the nearest grid point, with a warning if it does not fall exactly on one.

Initial conditions

The default is a discrete Dirac delta of height num_intervals / length at the origin. To start from any other profile, pass one value per grid point:

builder.set_initial_conditions(eigen_vector); // Eigen::VectorXd
builder.set_initial_conditions(std_vector); // std::vector<double>

The vector must have exactly num_intervals + 1 elements.

External force

The equation contains the term \(\partial_x \big(F(x) P(x,t)\big)\). The force \(F\) can be given in three ways. The last one you set is used, and a warning is printed when it replaces an earlier one.

builder.set_force(1.0); // constant force
builder.set_force([](double x) { return -2.0 * x; }); // function F(x)
builder.set_force(std::vector<double>(N + 1, 0.0)); // one value per grid point

The function is evaluated at the grid coordinates, measured from the origin. For position-dependent forces (a function or a vector), you can choose how the force matrix is discretised:

builder.set_force_scheme(Schemer::ForceSchemeType::FirstOrderUpwind); // more stable
builder.set_force_scheme(Schemer::ForceSchemeType::SecondOrderCentered); // default, more accurate

Stochastic resetting

Probability is removed from every point at a constant rate and added back at a reset target:

builder.set_reset_rate(0.5); // rate >= 0, 0 disables resetting (default)
builder.set_reset_index_zero(); // reset to the origin (default)
builder.set_reset_index(150); // or reset to a given grid index

Output and logging options

Method Default Meaning
set_delimiter(std::string) "\t" Column separator used in result and history output.
set_log_interval_percent(double) 5.0 Progress is logged every that many percent of a run() call. 0 disables logging.
set_log_file_path(std::string) "schemer_progress.log" File for progress messages. It is overwritten by each run() call.

Working with Config directly

All settings are stored in a Schemer::Config. You can read it, change it and pass it back. This is useful when running many similar simulations, as in a parameter sweep:

Schemer::Config config = builder.get_config();
for (double alpha : {0.6, 1.2, 1.8}) {
config.alpha = alpha;
Schemer::Runner runner = Schemer::Builder().set_config(config).build();
runner.run(1000);
}

Running a simulation

Builder::build() returns a ready-to-use Schemer::Runner. If you need the precomputed data, call Builder::build_setup() instead. It returns a Schemer::Setup with the config, step matrix, initial state, origin index and force. You can then construct the runner yourself: Schemer::Runner runner(setup);.

Method Meaning
run(int steps) Advance by steps time steps.
run(int steps, std::ostream &history, int interval) Advance and write the state to history every interval steps.
reset() Go back to step 0 and the initial state.
get_values() Current state as Eigen::VectorXd.
get_values_vector() Current state as std::vector<double>.
get_setup() Copy of the Schemer::Setup.

Calls to run() add up: run(300); run(200); gives the same state as run(500);.

Output

Result files

save_result(const std::string &path) writes the configuration and the current state to a file. save_result(std::ostream &) does the same for any stream, such as std::ostringstream or std::cout. The format is:

#alpha: 1.5
#beta: 0
#sigma: 1
#length: 40
#dt: 0.001
#num_intervals: 1000
#theta: 0.5
#dx: 0.04
#grid_size: 1001
#delimiter: <configured delimiter>
#log_interval_percent: 0
#log_file_path: schemer_progress.log
#force_scheme: SecondOrderCentered
#reset_input_rate: 0
#initial_values: <N+1 values>
#force: <N+1 evaluated force values>
#x_coordinates: <N+1 positions>
#steps: 500
<N+1 values of the current state>

The header records the scalar configuration parameters, derived grid spacing and size, selected force scheme, and reset rate. values_input_vector is included only when custom initial values are selected; input-type labels and other configured input values are not written. The initial_values, evaluated force, and x_coordinates rows are always included. Vector values are separated by the configured delimiter, and each vector row ends with that delimiter. The completed step count and current state follow the header.

History files

run(steps, stream, interval) first writes the same # header (without #steps), but only if the stream is still empty. It then writes one line per saved state: at steps 0, interval, 2*interval, …, plus a final line after the last step. You can call run() several times with the same stream to append more rows. The first row of each later call repeats the last state of the previous call.

std::ofstream history("history.tsv");
runner.run(1000, history, 50);

Your own format

Use the grid coordinates together with the state to write data in any layout you need:

const Schemer::Setup setup = runner.get_setup();
const std::vector<double> x = setup.config.get_coordinates(setup.starting_index);
const std::vector<double> p = runner.get_values_vector();
const double dx = setup.config.get_dx();
// total probability: sum(p) * dx

Examples

Build the examples with CMake:

cmake -S . -B build -DSCHEMER_BUILD_EXAMPLES=ON
cmake --build build

Simple usage

Configure, run, read the state and save the result.

#include <iostream>
#include <Eigen/Dense>
#include <Schemer/Schemer.h>
int main() {
// 1. Configure the simulation with the Builder. Every setter returns a
// reference to the builder, so calls can be chained.
Schemer::Runner runner = Schemer::Builder()
.set_alpha(1.5) // stability index, alpha in (0, 2)
.set_beta(0.0) // skewness, beta in [-1, 1]
.set_sigma(1.0) // scale parameter
.set_length(20.0) // domain spans [-10, 10]
.set_num_intervals(200) // 201 grid points
.set_dt(0.01) // time step
.set_log_interval_percent(0) // disable progress logging
.build();
// 2. Advance the simulation by 500 time steps (t = 500 * dt = 5.0).
runner.run(500);
// 3. Read the current state.
const Eigen::VectorXd values = runner.get_values();
const double dx = runner.get_setup().config.get_dx();
std::cout << "Grid points: " << values.size() << '\n';
std::cout << "Total probability: " << values.sum() * dx << '\n';
std::cout << "Value at x = 0: " << values(runner.get_setup().starting_index) << '\n';
// 4. Save the configuration and the final state to a file.
runner.save_result("simple_result.tsv");
return 0;
}

Advanced usage

Drift, force functions and vectors, force schemes, stochastic resetting, a custom initial state and origin, editing a Config, reset(), build_setup() and error handling.

#include <cmath>
#include <functional>
#include <iostream>
#include <numbers>
#include <stdexcept>
#include <vector>
#include <Eigen/Dense>
#include <Schemer/Schemer.h>
// Mean position of the distribution, computed on the simulation grid.
static double mean_position(const Schemer::Runner &runner) {
const Schemer::Setup setup = runner.get_setup();
const std::vector<double> x = setup.config.get_coordinates(setup.starting_index);
const Eigen::VectorXd p = runner.get_values();
const double dx = setup.config.get_dx();
double mean = 0.0;
for (Eigen::Index i = 0; i < p.size(); ++i) {
mean += x[static_cast<std::size_t>(i)] * p(i) * dx;
}
return mean;
}
int main() {
// A base builder shared by all the runs below.
Schemer::Builder base;
base.set_alpha(1.2)
.set_beta(0.5)
.set_sigma(1.0)
.set_length(40.0)
.set_num_intervals(400)
.set_dt(0.005)
.set_theta(0.5)
.set_log_interval_percent(10)
.set_log_file_path("advanced_progress.log");
// --- 1. Constant drift --------------------------------------------------
Schemer::Runner drift_runner = Schemer::Builder(base)
.set_drift(1.0)
.build();
drift_runner.run(400);
std::cout << "Drift: mean = " << mean_position(drift_runner) << '\n';
// --- 2. Position-dependent force F(x), choosing the force scheme -------
// Harmonic potential: F(x) = -2x pulls the distribution towards x = 0.
const std::function<double(double)> harmonic = [](const double x) { return -2.0 * x; };
Schemer::Runner runner = Schemer::Builder(base)
.set_force(harmonic)
.build();
runner.run(400);
std::cout << "mean = " << mean_position(runner) << '\n';
// --- 3. Force given as one value per grid point ------------------------
const Schemer::Config config = base.get_config();
const std::vector<double> x = config.get_coordinates(config.num_intervals / 2);
std::vector<double> force_values(x.size());
for (std::size_t i = 0; i < x.size(); ++i) {
force_values[i] = -4.0 * std::sin(x[i]);
}
Schemer::Runner vector_force_runner = Schemer::Builder(base)
.set_force(force_values)
.build();
vector_force_runner.run(400);
std::cout << "Force vector: mean = " << mean_position(vector_force_runner) << '\n';
// --- 4. Stochastic resetting --------------------------------------------
// Probability is removed everywhere at the given rate and returned to the
// reset target (the origin by default, or any grid index).
Schemer::Runner reset_runner = Schemer::Builder(base)
.set_drift(1.0)
.set_reset_rate(0.5)
.set_reset_index_zero()
.build();
reset_runner.run(400);
std::cout << "Drift + reset: mean = " << mean_position(reset_runner) << '\n';
// --- 5. Custom initial conditions and origin position -------------------
// Place x = 0 at 15 length units from the left edge and start from a
// normalised Gaussian instead of the default Dirac delta.
Schemer::Builder gaussian_builder(base);
gaussian_builder.set_zero_distance(15.0);
const Schemer::Config gaussian_config = gaussian_builder.get_config();
const Eigen::Index zero_index = static_cast<Eigen::Index>(
std::round(15.0 / gaussian_config.get_dx()));
const std::vector<double> gx = gaussian_config.get_coordinates(zero_index);
Eigen::VectorXd initial(gaussian_config.get_size());
constexpr double width = 1.0;
for (Eigen::Index i = 0; i < initial.size(); ++i) {
const double xi = gx[static_cast<std::size_t>(i)];
initial(i) = std::exp(-xi * xi / (2.0 * width * width)) / (width * std::sqrt(2.0 * std::numbers::pi));
}
Schemer::Runner gaussian_runner = gaussian_builder
.set_initial_conditions(initial)
.build();
gaussian_runner.run(400);
std::cout << "Gaussian start: mean = " << mean_position(gaussian_runner) << '\n';
// --- 6. Editing a Config directly and rerunning -------------------------
Schemer::Config edited = base.get_config();
edited.alpha = 0.8;
edited.beta = -0.5;
Schemer::Runner config_runner = Schemer::Builder().set_config(edited).build();
config_runner.run(200);
const double mean_after_200 = mean_position(config_runner);
config_runner.reset(); // back to step 0 and the initial state
config_runner.run(200); // reproduces the same result
std::cout << "From Config: mean = " << mean_after_200
<< " (after reset: " << mean_position(config_runner) << ")\n";
// --- 7. Building a Setup and constructing the Runner manually -----------
const Schemer::Setup setup = Schemer::Builder(base).build_setup();
std::cout << "Step matrix: " << setup.step_matrix.rows() << " x " << setup.step_matrix.cols() << '\n';
Schemer::Runner manual_runner(setup);
manual_runner.run(100);
return 0;
}
