SchemerLib

Schemer is a header-only C++20 library that solves the one-dimensional space-fractional Fokker–Planck equation with an optional external force and stochastic resetting. It provides a builder-based API for configuring a simulation, running time steps, and saving results.

The equation

Schemer computes the time evolution of a probability density \(P(x,t)\) governed by

\begin{equation}\frac{\partial}{\partial t} P(x,t) = \underbrace{\frac{\partial}{\partial x} \big( F(x)\,P(x,t) \big)}_{\text{force}} + \underbrace{K \cdot \frac{\partial^\alpha}{\partial |x|^\alpha} P(x,t)}_{\text{fractional diffusion}} \underbrace{-\, r\,P(x,t) + r\,\delta(x - x_r)}_{\text{stochastic resetting}} \end{equation}

with the initial condition \(P(x, 0) = \delta(x)\) by default, or any profile you supply.

The process described is a Lévy flight inside any external potential (or with a drift) with optional resetting. Applied numerical scheme is tailored for researching First-passage statistics.

Terms and parameters

Every symbol in the equation corresponds to one setting of Schemer::Builder (stored in Schemer::Config):

Symbol Meaning Builder method Config field Range / default
\(\alpha\) Stability index, the order of the fractional derivative set_alpha() Schemer::Config::alpha \((0, 2)\), required
\(\beta\) Skewness of the fractional operator set_beta() Schemer::Config::beta \([-1, 1]\), default \(0\) (must be \(0\) for \(\alpha = 1\))
\(K\) Scale (fractional diffusion coefficient) set_sigma() Schemer::Config::sigma \(\ge 0\), default \(1\)
\(F(x)\) External force set_force() Schemer::Config::force_input default \(F \equiv 0\)
\(r\) Resetting rate set_reset_rate() Schemer::ResetInput::rate \(\ge 0\), default \(0\) (off)
\(x_r\) Resetting position set_reset_index_zero(), set_reset_index() Schemer::Config::reset_input default \(x_r = 0\)
\(P(x,0)\) Initial condition set_initial_conditions() Schemer::Config::values_input default \(\delta(x)\)

Numerical method

  • Grid. The domain of length \(L\) (set_length()) is divided into \(N\) intervals (set_num_intervals()), giving \(N+1\) points \(x_i = (i - i_0)\,\Delta x\) with \(\Delta x = L/N\). The origin index \(i_0\) is set with set_zero_middle(), set_zero_index() or set_zero_distance().
  • Space. The fractional term becomes a dense matrix whose form depends on whether \(0 < \alpha < 1\), \(\alpha = 1\), or \(1 < \alpha < 2\) (see Schemer::FractionalScheme). A position-dependent force is discretised with either Schemer::ForceSchemeType::FirstOrderUpwind ( more stable) or Schemer::ForceSchemeType::SecondOrderCentered (default, more accurate).
  • Time. With all spatial terms collected into an operator \(A\), each step of size \(\Delta t\) (set_dt()) uses the \(\theta\)-scheme

    \begin{equation} \big(I + \theta\,\Delta t\,A\big)\,P^{n+1} = \big(I - (1-\theta)\,\Delta t\,A\big)\,P^{n}, \end{equation}

    where \(\theta = 0\) is explicit, \(\theta = 1/2\) (default) is Crank–Nicolson and \(\theta = 1\) is implicit (set_theta()). The resulting step matrix is computed once, when the simulation is built.
  • Boundaries. Absorbing boundary conditions are used, probability that leaves the domain is lost. While acceptable for first passage time, longer simulations' results may become inaccurate.
  • Stability. The stability of resulting matrix is heavily dependent on multiple parametres, especially \(\alpha\) and force \(F(x)\). Using Schemer::ForceSchemeType::FirstOrderUpwind the matrix is more stable at the cost of accuracy.

Getting started

#include <Schemer/Schemer.h>
int main() {
Schemer::Runner runner = Schemer::Builder()
.set_alpha(1.5) // α
.set_beta(0.0) // β
.set_sigma(1.0) // K
.set_force(0.5) // F(x) = 0.5
.set_length(20.0)
.set_num_intervals(200)
.set_dt(0.01)
.build();
runner.run(500); // P(x, t = 5)
runner.save_result("result.tsv");
}
